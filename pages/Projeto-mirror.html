Projeto MirrorFashion

Informações do Projeto

O projeto consistiu no desenvolvimento do "Mirror Fashion", a interface de uma plataforma de comércio eletrônico fictícia voltada para o segmento de moda. O objetivo foi estruturar e codificar uma página web completa a partir de um projeto visual de alta fidelidade, garantindo precisão no layout e na experiência do usuário. Para a execução, foram empregadas as tecnologias essenciais do desenvolvimento web front-end: HTML e CSS. O HTML (HyperText Markup Language) foi utilizado para estruturar semanticamente o conteúdo, definindo os elementos fundamentais da página. Em complemento, o CSS (Cascading Style Sheets) foi aplicado para projetar a identidade visual e o design responsivo, controlando com precisão o posicionamento dos elementos, a tipografia, a paleta de cores e a estética geral da aplicação.

Implementação

Toda a estruturação do código HTML e a estilização via CSS foram implementadas do zero para as páginas principais do site (Home e Sobre). O desenvolvimento exigiu a implementação técnica de:

Estrutura Semântica:

O código HTML foi construído utilizando as tags semânticas corretas introduzidas no HTML5. Isso incluiu a separação estrutural lógica com o cabeçalho (header), navegação principal (nav), áreas de conteúdo segmentadas (section) e rodapé (footer).

Seletores e Identificadores:

Foram utilizadas classes CSS para elementos que se repetem no layout (como .container para centralização, e .painel para as vitrines de roupas) e identificadores (id) para elementos únicos da página, permitindo a aplicação de estilos de forma direcionada.

Layout e Alinhamento:

O posicionamento dos blocos foi resolvido com o uso da propriedade float (para alinhar o menu de departamentos ao lado do banner de destaque) e a introdução inicial ao modelo display: flex para a criação das grades de produtos (painéis de novidades e mais vendidos), permitindo a organização fluida em linhas e colunas.

Técnicas de magem:

Utilizou-se o redimensionamento de imagens nativo no CSS e a aplicação de ícones de navegação diretamente pela folha de estilos através da propriedade background-image, técnica que ajuda a manter a marcação HTML mais limpa e focada em conteúdo.
