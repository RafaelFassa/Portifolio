# Portfólio — Rafael Fassa

Portfólio pessoal desenvolvido como Trabalho de Conclusão de Curso (TCC) do curso de **Sistemas para Internet** da **Fatec Lins**.

O site reúne apresentação pessoal, projetos desenvolvidos ao longo do curso, currículo e formas de contato.

## Tecnologias

- HTML5 e CSS3
- Bootstrap 5.3 e Bootstrap Icons
- FormSubmit (envio do formulário de contato)

## Estrutura

```
index.html        Página principal (Home, Sobre Mim, Projetos, Currículo, Contato)
pages/            Página de detalhes de cada projeto
css/              Estilos (style.css e projetos.css)
img/              Imagens dos projetos e do site
documents/        Currículo em PDF
```

## Projetos apresentados

| Projeto | Tecnologias |
|---|---|
| Mirror Fashion | HTML5, CSS3 |
| Portfólio One Page | HTML5, CSS3 (Flexbox) |
| Diagrama Entidade-Relacionamento (DER) | MySQL Workbench |
| Criação de Banco de Dados | MySQL, SQL |
| CRUD em Java | Java, MySQL, HTML5, Bootstrap |
| Consumo de Web Service (SOAP) | Java, Eclipse, Apache Tomcat, SoapUI |

## Como executar

O projeto é estático e não precisa de instalação. Basta abrir o arquivo `index.html` no navegador ou usar uma extensão como o Live Server do VS Code.
